# Проверка HW 60

Дата: 14 ноября 2026. Среда фактического запуска: Node.js v22.16.0, npm 10.9.2, Linux. Проект и GitHub Actions настроены на Node.js 24; эта версия отдельно в среде не запускалась.

## Выполнено

- `npm run test:native`: **66 тестов, 66 passed, 0 failed, 0 skipped**. Полный вывод: [native-tests.txt](native-tests.txt); [скриншот итогового вывода](native-tests.png).
- `npm run lint`: синтаксис JavaScript/MJS и JSON проверен встроенным Node.js; это не ESLint.
- `npm run build`: успешно.
- В числе нативных тестов — 13 проверок настоящего HTTP для статического preview: файлы под `/repository-check/`, индекс, HEAD, заголовки, неизвестные и небезопасные пути, неправильная кодировка URL, недопустимый метод. Это не HTTP-проверки Express.

Проверены обе коллекции Map: CRUD, уникальность ID при одинаковом времени, изоляция экземпляров, копии возвращаемых данных, некорректные и пустые значения, сохранение ID при обновлении, лишние поля и отсутствие ресурса. Контроллеры и обработчики ошибок проверены напрямую с объектами ответа. Эти тесты не создают Express-приложение и не подтверждают прохождение HTTP-запросов через Express.

`npm run build` создал статический деморежим с общей логикой коллекций. Подготовлены 16 дополнительных реальных HTTP-тестов (`npm run test:http`), но без Express они не запускались.

## Проверка интерфейса

В Chromium отдельно выполнены DOM-проверки: переключение коллекций и схемы формы, поиск, редактирование существующей записи, ответы 200/400/404 локального демо, подтверждённое удаление и отмена следующего удаления через Escape. Создание через `crypto.randomUUID()` в непривилегированном DOM-контексте не проверялось; эта операция включена в подготовленные E2E-сценарии для localhost/HTTPS.

Вёрстка проверена при ширине 1440 и 390 px, без горизонтального переполнения на 390 px. Изображения: [desktop](preview-desktop.png), [mobile](preview-mobile.png).

Переход Chromium на localhost заблокирован политикой среды (`net::ERR_BLOCKED_BY_ADMINISTRATOR`). Для перечисленных DOM-проверок HTML/CSS/JavaScript загружались через `setContent`, без проверки загрузки ES-модулей по HTTP. Скриншоты интерфейса и DOM-проверки **не являются сквозными E2E-тестами**. Встроенный preview отдельно проверен через настоящий HTTP.

Установка npm-пакетов фактически попыталась обратиться к registry.npmjs.org и завершилась `EAI_AGAIN`. Поэтому 23 исходных Vitest-тестов не выполнены. Подготовленные `npm run check`, `npm run test:browser`, `npm run test:report` полностью не выполнялись. Настоящий сервер Express, HTTP-тесты Express и запросы Postman не проверены в работе. GitHub Actions не запускался, репозиторий и опубликованный сайт не создавались.

Исходные тесты и `vitest.setup.js` сохранены побайтно. Команда `npm run test:report` создаёт отчёт и скриншот только после настоящего запуска Vitest; скриншот успешного Vitest не подставлен.
