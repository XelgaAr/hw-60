# REST API

Базовый локальный адрес: `http://localhost:3000`. JSON-тело требует `Content-Type: application/json`.

| Метод | Путь | Успех | Ошибки |
|---|---|---|---|
| GET | `/` | 200 `Get root route`, text/plain | — |
| GET | `/users` | 200 `[{ id, name }]` | — |
| POST | `/users` | 201 `{ id, name }` + Location | 400 |
| GET | `/users/:userId` | 200 `{ id, name }` | 404 |
| PUT | `/users/:userId` | 200 `{ id, name }` | 400 / 404 |
| DELETE | `/users/:userId` | 204, пустое тело | 404 |
| GET | `/articles` | 200 `[{ id, title }]` | — |
| POST | `/articles` | 201 `{ id, title }` + Location | 400 |
| GET | `/articles/:articleId` | 200 `{ id, title }` | 404 |
| PUT | `/articles/:articleId` | 200 `{ id, title }` | 400 / 404 |
| DELETE | `/articles/:articleId` | 204, пустое тело | 404 |

Строки обрезаются по краям. `null`, числа, массивы, объекты, отсутствие поля и строки только из пробелов отвергаются. Дополнительные поля, включая переданный клиентом `id`, не сохраняются. PUT проверяет существование ресурса до изменения; невалидные данные не меняют коллекцию. Возвращаемые объекты не предоставляют ссылку на внутреннюю запись Map.

Некорректный JSON — 400, тело больше 32 KiB — 413, неподдерживаемая кодировка JSON-парсера — 415. Ошибки содержат стандартный текст, без stack trace или внутренних данных. Непредвиденная ошибка — 500. Неподдерживаемый маршрут или неописанный метод проходит в общий 404. HEAD/OPTIONS используют стандартное поведение Express.

## Ручная проверка

```bash
curl http://localhost:3000/users
curl http://localhost:3000/articles
```

Для полного CRUD импортируйте `docs/postman-collection.json` в Postman. Коллекция сохраняет ID созданных ресурсов и использует их в следующих запросах. `docs/requests.http` содержит те же основные примеры для HTTP-клиента в VS Code. Коллекция подготовлена; запуск Postman в среде подготовки не выполнялся.

## Интерфейс

`http://localhost:3000/demo/` — клиент с настоящим fetch к API на том же origin. `/demo/config.js` включает live-режим. Статическая сборка использует `live = false` и общие Map-коллекции из `src/domain`; сетевой сервер в Pages не появляется.

Данные хранятся только в памяти процесса (или вкладки в деморежиме). Это учебное API без авторизации. Не храните в нём конфиденциальные данные и не публикуйте его как защищённый production-сервис. Для внешнего Node.js-хостинга потребуется `HOST=0.0.0.0`, выданный платформой `PORT`, а для постоянных данных — отдельная БД. GitHub Pages публикует только статический интерфейс.
