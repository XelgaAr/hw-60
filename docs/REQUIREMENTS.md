В задании есть общая фраза о JSON для всех маршрутов и отдельное требование текстовых ошибок. Принят конкретный контракт, совпадающий с исходными тестами: успешные ресурсы — JSON, ошибки и корень — текст, 204 — пустое тело.

Идентификатор включает время и случайный UUID. Это предотвращает коллизии быстрых запросов и сохраняет возможность проверить непредвиденную ошибку через `Date.now`, как в исходном тесте.

Опциональный публичный `/error-test` не добавлен: ошибка проверяется тестами без искусственной аварийной точки на опубликованном API. `app`/`server` экспортируются всегда; `listen` выполняется только при непосредственном запуске, чтобы импорт не занимал порт.

Дополнительный интерфейс находится в `/demo/` и не изменяет ответ `/`. GitHub Pages содержит отдельный статический режим с явной маркировкой; он не выдаётся за работающий Express-сервер. Авторизация и постоянная БД не требуются этим заданием и не реализованы.
